# Retrieval release check

Generated by `vectraudit init --backend {backend}`. Every pull request records the target
branch's retrieval setup and this branch's on the same labelled queries, then
`vectraudit check` decides pass / fail / error / not comparable under `policy.json`.

## Set up (about 15 minutes)

1. **Connection.** Edit `connection.json` for your {backend} setup.{secret_note}
2. **Queries.** Replace `queries.csv` with 30+ real questions and the ids of the documents
   that answer them (`doc-1:2; doc-7` = grade 2 and grade 1). Then:

   ```bash
   vectraudit dataset import retrieval/queries.csv --out retrieval/dataset.jsonl --tags-column tags
   vectraudit dataset embed retrieval/dataset.jsonl --model YOUR-EMBEDDING-MODEL
   vectraudit dataset stats retrieval/dataset.jsonl --policy retrieval/policy.json
   ```

3. **Try it locally.**

   ```bash
   vectraudit record --connection retrieval/connection.json --dataset retrieval/dataset.jsonl --out baseline.json
   vectraudit record --connection retrieval/connection.json --dataset retrieval/dataset.jsonl --out candidate.json
   vectraudit check baseline.json candidate.json --policy retrieval/policy.json --html report.html
   ```

4. **CI.** Commit `retrieval/`, `.github/actions/` and
   `.github/workflows/retrieval-check.yml`. The workflow is one step: the
   `retrieval-check` action installs the pinned release, records the target branch and the
   pull request on the same runner, checks them and keeps the report. Set repository
   variable `VECTRAUDIT_DISTRIBUTION_REPOSITORY` to the private distribution repository
   provided during onboarding (never the source repository). Set `VECTRAUDIT_VERSION` and
   `VECTRAUDIT_SHA256` in the workflow to the reviewed release version and wheel checksum.
   Add repository secret `VECTRAUDIT_DOWNLOAD_TOKEN` (a customer-specific read-only
   credential scoped only to that distribution repository){ci_secret}.
   The installer refuses missing pins or a changed wheel before installing it.
5. **Upgrade.** After installing a newer release locally, refresh only the CI files with
   `vectraudit init --backend {backend} --ci-only --force`, then update the two pins.

See the release-check guide for the dataset, connection and policy formats.
